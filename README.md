### 1. Tic Tac Toe
Location: [projects/TicTacToe](projects/TicTacToe)

A playful and polished Tic Tac Toe experience with custom themes, multiple board sizes, and both local multiplayer and bot mode. This project focuses on game logic, visual polish, and interactive UI design.

Features:
- Classic 3x3, 4x4, and 5x5 modes
- Mega board gameplay
- 2-player and bot opponent options
- Multiple theme presets and dark/light appearance toggle

### 2. MDoNER: Disaster Alerting for NER, India
Location: [projects/MDoNER](projects/MDoNER)

MDoNER is a concept-driven early-warning platform designed for landslide risk monitoring in North East India. It presents a realistic approach to data-driven disaster response, combining AI, monitoring dashboards, and alert systems.

Features:
- Risk dashboard and district monitoring
- AI-inspired prediction and alerting concept
- Real-time simulation of hazard indicators
- Report submission and local data persistence
- Focus on early warning and public safety

### 3. F-Watch
Location: [projects/F-Watch](projects/F-Watch)

A YouTube-inspired media platform mockup with a modern streaming interface, profile setup, category browsing, video cards, search, and modal-based playback. This project demonstrates layout design and interactive front-end behavior.

Features:
- Sign-in and profile creation flow
- Responsive video streaming-style layout
- Search and discovery sections
- Category-based content layout
- Video modal preview experience

### 4. To Do List
Location: [projects/ToDoList](projects/ToDoList)

A productivity-focused task manager for organizing daily work, upcoming goals, and personal projects. This app is designed to help users manage tasks efficiently with multiple views and sorting tools.

Features:
- Add, edit, delete, and track tasks
- Priority and status filtering
- Project-based organization
- Search and sorting tools
- Calendar and overview views
- Import/export support

### 5. Calculator
Location: [projects/Calculator](projects/Calculator)

A scientific calculator application built for advanced calculations and everyday use. It includes a modern UI, memory functions, history tracking, and angle-mode support for more advanced mathematical operations.

Features:
- Scientific functions including trigonometry and logarithms
- Memory operations and history
- Result formatting and copy functionality
- Keyboard-style layout and modern interface
- Dark/light theme support
